# 8086 汇编可视化模拟器 · Visual 8086 Simulator

**简体中文** | [English](README.en.md)

面向 **微机原理 / 汇编语言** 课程的可视化实验环境。在一个界面内完成「编辑代码 → 汇编 → 运行 / 单步 → 观察寄存器、标志位、内存、堆栈与 DOS 输入输出」的完整闭环，参考 EMU8086、TASM、DOSBox 的交互理念，以现代可视化方式重新呈现。

纯前端实现，**无需联网、无需安装任何运行库**；同时提供 Electron 打包的 Windows 独立程序。

---

## 一、功能特性

- **两遍汇编器（MASM/TASM 风格）**
  - 完整段 `SEGMENT / ENDS / ASSUME / END` 与简化段 `.DATA / .CODE / .STACK`
  - 伪指令 `DB / DW / DD / DUP / EQU / = / ORG / OFFSET / SEG / PTR / $`
  - 标签前向引用、表达式运算（`+ - * / MOD & | XOR`）、字符串、字符常量
  - 错误带**源行号**精确定位，集中显示在日志面板
- **8086 指令集解释执行**
  - 数据传送、算术（含乘除、BCD 调整）、逻辑、移位/循环移位、串操作（`REP/REPE/REPNE`）
  - 控制转移：无条件/条件跳转、`LOOP` 系列、`CALL / RET / RETF / INT / IRET`
- **真实的硬件模型**
  - 1 MB 内存，物理地址 = 段×16 + 偏移，**小端序**
  - 8 个通用寄存器（含 8 位拆分 AH/AL…）、4 个段寄存器、9 个标志位
  - 独立堆栈段，`PUSH / POP / CALL / INT` 真实压栈，堆栈视图实时更新
- **类 DOS 控制台**
  - 80×25 字符屏幕，CRT 磷光效果与扫描线，支持回车/换行/退格/制表符
  - `INT 21h` 字符/字符串/行缓冲输入输出，**阻塞式键盘输入**状态机
- **完全可视化**
  - 当前执行行高亮、断点（点击行号）、寄存器变化闪烁、标志位 LED、内存 Hex+ASCII 转储
  - 反汇编视图、执行速度滑块、三套配色（磷绿 / 琥珀 / 冰蓝）

## 二、快速开始（三种方式）

### 方式 1：浏览器直接打开（零依赖，推荐先试）

双击项目根目录下的 **`启动模拟器.bat`**，或直接双击 **`index.html`**，即可在默认浏览器中使用，无需安装任何东西。

### 方式 2：Electron 桌面窗口（开发模式）

前置要求：已安装 [Node.js](https://nodejs.org)。

```powershell
npm install
npm start
```

### 方式 3：打包为 Windows 独立 exe

```powershell
npm run dist
```

产物位于 `dist\8086汇编可视化模拟器.exe`，单文件便携版，可拷贝到任意 Windows 电脑直接运行。

## 三、使用步骤（上手教程）

1. **加载代码**：从右上角「内置示例」下拉选择一个程序，或直接在左侧编辑器中编写/粘贴汇编代码。
2. **汇编加载**：点击工具栏「汇编加载」（或按 `F5`）。成功后日志面板显示段表与符号信息，当前行高亮；若有语法错误，会在这里列出具体行号与原因。
3. **运行或单步**：
   - 「运行」（`F6`）：连续执行，可用「速度」滑块调节快慢，「暂停」随时停下。
   - 「单步」（`F7`）：每次执行一条指令，便于逐条观察。
4. **设置断点**：点击编辑器左侧行号，出现红点即断点；再次点击取消。运行到断点会自动暂停。
5. **键盘输入**：当程序执行到输入指令（如 `INT 21h / AH=01h`）时，状态栏显示「等待输入」。先点击中间 CRT 屏幕使其聚焦，再按键盘；输入完成后程序自动继续。
6. **观察状态**：右侧实时查看寄存器与标志位，底部查看内存，堆栈视图显示栈内容；「复位」可清空并回到初始状态。

## 四、界面与操作

| 区域 | 说明 |
|---|---|
| 源代码编辑器 | 左侧，行号 + 语法高亮；点击行号切换断点；Tab 缩进 |
| DOS 控制台 | 中部 CRT 屏幕，程序输出与键盘输入；等待输入时点击屏幕后按键 |
| 寄存器 | 右侧，16 位值 + 8 位拆分（AH/AL），变化时高亮 |
| 标志位 | 9 个 LED：CF PF AF ZF SF TF IF DF OF |
| 堆栈 | 从 SS:SP 起逐字显示，栈顶高亮 |
| 内存查看器 | 底部，选择 DS/SS/ES/CS 与偏移，Hex + ASCII，可跟随 IP |
| 反汇编 | 控制台下方，当前 CS:IP 附近的指令 |

**快捷键**：`F5` 汇编加载 · `F6` 运行 · `F7` 单步

## 五、支持的 DOS / BIOS 中断

| 中断 | 功能 | 作用 |
|---|---|---|
| INT 21h | AH=09h | 输出 DS:DX 处 `$` 结尾字符串 |
| INT 21h | AH=02h | 输出 DL 中字符 |
| INT 21h | AH=01h | 带回显字符输入（阻塞） |
| INT 21h | AH=07h/08h | 无回显字符输入 |
| INT 21h | AH=0Ah | 行缓冲输入，回车结束 |
| INT 21h | AH=4Ch / 00h | 程序退出 |
| INT 10h | AH=0Eh | 电传方式输出字符 |
| INT 16h | AH=00h | 键盘字符输入 |
| INT 20h | — | 程序终止 |

数字格式：`100` 十进制 · `0FFh` 十六进制 · `1010b` 二进制 · `'A'` 字符常量。

## 八、技术架构说明

- 汇编器第一遍建立段表与符号偏移，第二遍生成内部指令表示（IR）并加载数据；段地址按 16 字节对齐自动分配（起始 `1000h`）。
- 代码以 IR 形式由 CS:IP 索引执行，IP 按指令字节长度推进；数据、堆栈、变量寻址全部走真实内存读写与段:偏移物理地址。
- 阻塞输入通过异步状态机实现：CPU 挂起 → 控制台接收键盘 → 写回寄存器/缓冲区 → 恢复执行；连续运行中遇输入，完成后自动续跑。
